# Notes

Простое приложение для заметок на Android.

## Возможности
- Текстовое поле для заметок
- Кнопка **Сохранить**
- Кнопка **Очистить**
- Автосохранение при сворачивании приложения
- Интерфейс на русском языке

## APK

Готовый APK (~13 КБ) можно скачать из этого чата (файл notes.apk).

**Минимальная версия Android:** 5.0 (API 21)

## Установка
1. Скачай `notes.apk`
2. На телефоне разреши установку из неизвестных источников (Настройки → Безопасность / Приложения)
3. Открой файл и установи

## Исходный код
Полный исходный код в папке [`app/`](app/).

Собрано вручную без Gradle (aapt2 + javac + d8 + apksigner).
