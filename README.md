# Notes

Простое приложение для заметок на Android.

## Возможности
- Текстовое поле для заметок
- Кнопка **Сохранить**
- Кнопка **Очистить**
- Автосохранение при сворачивании приложения
- Интерфейс на русском языке

## Скачать APK

Файл APK: [notes.apk](notes.apk)

Если бинарный файл не скачивается нормально, используй `notes.apk.b64`:

```bash
base64 -d notes.apk.b64 > notes.apk
```

**Размер APK:** ~13 КБ  
**Минимальная версия Android:** 5.0 (API 21)

## Установка
1. Скачай `notes.apk`
2. На телефоне разреши установку из неизвестных источников (Настройки → Безопасность)
3. Открой файл и установи

## Исходный код
Код лежит в папке `app/`.

Собрано вручную без Gradle (aapt2 + javac + d8 + apksigner).
